# db_InformasiKasir_Riyanti
Sistem Informasi Kasir berbasis web menggunakan PHP dan MySQL untuk mengelola data barang, kategori, pelanggan, serta transaksi penjualan. Sistem ini dilengkapi dengan fitur pengelolaan stok barang, pencatatan transaksi, perhitungan total pembayaran, dan kembalian secara otomatis.
